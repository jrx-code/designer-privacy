JI Designer - privacy policy

Applies to the Android application eu.iwanus.designer. Last updated 11 November 2026.

Short version

There is no account, no sign-up, no analytics and no advertising. The application has no server of its own and collects nothing. Everything it keeps stays on the device, and the only data that leaves the device is what you send, to the service you chose, when you ask for a render.

What is stored on the device

  • Your settings: the mode, the room and style you last used, and the palette strength.
  • In standalone mode, the API key you entered, encrypted with the Android keystore.
  • In home mode, the address of your own server and a device token for it, encrypted the same way.

Nothing in this list is backed up to a cloud: the application sets android:allowBackup="false". Uninstalling removes all of it.

What leaves the device, and where it goes

Standalone mode. The photo you choose is read on the device and never uploaded. The text prompt built from its palette is sent to the image service you configured, with your own API key, and the picture that service returns comes back. That service is your contractual counterparty, not ours, and its own privacy policy applies to that request.

Home mode. The photo, the prompt and the result travel between the application and the JI Designer server you paired with, which is a machine on your own network. Where that server is configured to render on a hosted engine, the prompt reaches that engine under the key stored on the server.

Palette descriptions. Asking what a palette is sends that library entry and the language you picked to the same paired server. The text is written by a model on your own network by default; if the server is configured to use a hosted text model instead, the palette's colours and the entry's name reach that service under the key stored on the server, exactly as a render does. No photo is sent for a description.

What the developer receives

Nothing. The developer operates no service for this application, receives no telemetry, no crash reports and no copies of your photos, prompts or results.

Permissions

  • Internet, to reach the image service or your own server.
  • No storage permission. Photos are chosen through the Android photo picker, which hands the application a one-time read of the single file you picked and nothing else.

Children

The application is not directed at children and collects no personal data from anyone.
